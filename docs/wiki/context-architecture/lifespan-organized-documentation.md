# Lifespan Organized Documentation

## Current Understanding

Lifespan organized documentation separates working material by how it should influence current tasks. Active plans, accepted decisions, stable references, and archived history need different authority signals so agents do not confuse current work with provenance.

Active documents hold living plans for work in progress. Decision records preserve accepted choices and reasons. Reference documents hold stable runbooks, registries, and integration guides. Archive documents preserve completed history with clear signals that they should not be followed as current instructions.

## Practice Boundaries

- Keep active plans separate from accepted decisions and stable references.
- Use decision records to prevent settled choices from being re-litigated.
- Use reference documents for reusable runbooks, registries, and integration guides.
- Mark archived history clearly so it remains provenance, not current instruction.
- Route agents to documents by lifespan when authority matters more than topic grouping.
