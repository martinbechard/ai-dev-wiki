# October 2026 Development Digest

## Current Understanding

### 2026-10-04

- [Repository-configured AI code review](../coding-practices/repository-configured-ai-code-review.md) and [code review evals and rubrics](../verification-and-evals/code-review-evals-and-rubrics.md) now preserve API-triggered review governance, default-effort drift, and downstream human acceptance.

- [Layered AI code review roles](../coding-practices/layered-ai-code-review-roles.md) now keeps repository instructions, deterministic analysis, product-fit review, design review, and human review as separate evidence layers.

- [Durable instructions and skill files](../adoption-and-operating-model/durable-instructions-and-skill-files.md) now treats named models inside instructions as configurable dependencies with owner review and stale-reference checks.

- [Prompt injection and untrusted content](../governance-and-risk/prompt-injection-and-untrusted-content.md) now requires tool-result labelling, user-authored confirmation, pre-action prevention, and constrained rendering for untrusted agent output.

- [Governance controls for agents](../governance-and-risk/governance-controls-for-agents.md) now frames action sequences, scoped identities, least-privilege tools, approval checkpoints, per-run limits, kill switches, and action-level logs as control-plane evidence.

- [Structured output and drafter patterns](../application-patterns/structured-output-and-drafter-patterns.md) now records stale-state clearing, retry behavior, provider-native schema, tool-call schema, and raw JSON-schema limits.

- [User-visible progress and runtime telemetry](../application-patterns/user-visible-progress-and-runtime-telemetry.md) now reconstructs cross-system workflow journeys, human judgment points, owner handoffs, and error-amplification paths.

- [Local model runtime harness](../application-patterns/local-model-runtime-harness.md) and [harness sizing by workflow complexity](../application-patterns/harness-sizing-by-workflow-complexity.md) now pair local setup with security limits, injection tests, tool metrics, refusal calibration, and CI evaluation gates.

- [Workflow before model selection](../adoption-and-operating-model/workflow-before-model-selection.md) and [research-plan-implement-review lifecycle](../agent-workflows/research-plan-implement-review-lifecycle.md) now route autonomy by task risk, boundaries, reviewable increments, independent verification, and lifecycle checkpoints.

- [Outcome alignment and process autonomy](../adoption-and-operating-model/outcome-alignment-and-process-autonomy.md) now measures AI-assisted development by review time, escaped defects, rework, security findings, customer impact, and accepted outcomes.

### 2026-10-03

- [Repository-configured AI code review](../coding-practices/repository-configured-ai-code-review.md) and [code review evals and rubrics](../verification-and-evals/code-review-evals-and-rubrics.md) now preserve API-triggered review provenance, requested effort, default policy, and automation actor evidence.

- [Multi-reviewer AI code review](../coding-practices/multi-reviewer-ai-code-review.md) now treats adversarial critic loops as bounded, source-grounded disagreement workflows where unsupported objections are retracted before repair.

- [AI-assisted TDD](../coding-practices/ai-assisted-tdd.md) now records fail-first tests as the agent feedback interface and treats test weakening as a reviewable boundary change.

- [Agent control flow selection](../agent-workflows/agent-control-flow-selection.md), [AI process layer and workflow state](../application-patterns/ai-process-layer-and-workflow-state.md), and [declarative agent workflow artifacts](../application-patterns/declarative-agent-workflow-artifacts.md) now preserve background-agent state, session lineage, checkpoints, structured results, and dynamic workflow contracts.

- [Browser-agent runtime boundaries](../application-patterns/browser-agent-runtime-boundaries.md) and [human-agent approval boundaries](../adoption-and-operating-model/human-agent-approval-boundaries.md) now capture desktop app-control allowlists, OS permission evidence, acting identity, and return-to-human checkpoints.

- [Agent identity and delegated authority](../governance-and-risk/agent-identity-and-delegated-authority.md) and [tool call and MCP governance](../retrieval-and-tools/tool-call-and-mcp-governance.md) now preserve remote MCP identity mode, grant evidence, workload admission, and fail-closed denial evidence.

- [RAG tools and MCP practice](../retrieval-and-tools/rag-tools-and-mcp-practice.md) and [AI assisted security repair gates](../governance-and-risk/ai-assisted-security-repair-gates.md) now freeze MCP prompt-injection action chains and retain raw outputs, normalized outputs, policy decisions, approvals, and rollback evidence.

- [Application harness patterns](../application-patterns/application-harness-patterns.md) now separates pre-action guidance, action execution, post-action sensors, and selective human escalation gates as harness controls.

### 2026-10-02

- [Declarative agent workflow artifacts](../application-patterns/declarative-agent-workflow-artifacts.md) now treats code-defined dynamic workflows as reviewable staged-step, handoff, verification, user-input, and pause/resume contracts.

- [Browser-agent runtime boundaries](../application-patterns/browser-agent-runtime-boundaries.md) now extends governed runtime controls to desktop app control approvals, OS permissions, organization policy, and reset procedures.

- [Verification loops and evals](../verification-and-evals/verification-loops-and-evals.md) now records CI/check retention, coverage skips, code-scanning start conditions, and async merge polling as verification-state evidence.

- [Agent governance infrastructure](../governance-and-risk/agent-governance-infrastructure.md) now joins app-control policy, runtime containment, audit-trail availability, provider/network controls, evidence retention, and async-operation state.

- [Agent incident reporting](../governance-and-risk/agent-incident-reporting.md) now separates unexpected activity, confirmed compromise, negative findings, third-party notification, and destructive-file-operation evidence.

- [Agent session recovery](../application-patterns/agent-session-recovery.md) and [coding-agent runtime updater integrity](../source-workflows/coding-agent-runtime-updater-integrity.md) now track crash recovery, turn preservation, secret redaction, provider allowlists, and network-disable controls.

- [RAG provenance, ranking, and chunking](../retrieval-and-tools/rag-provenance-ranking-and-chunking.md) and [agent eval failure diagnosis](../verification-and-evals/agent-eval-failure-diagnosis.md) now split retrieval, grounding, final-answer, trace, replay, and comparison-run failure classes.

- [Agent ownership rosters](../adoption-and-operating-model/agent-ownership-rosters.md) now connects dashboard agent queues, issue assignment, audit-trail readiness, and incident ownership before agent work is treated as governed.

### 2026-10-01

- [Repository-configured AI code review](../coding-practices/repository-configured-ai-code-review.md) now treats review effort, custom instructions, `AGENTS.md`, skills, MCP context, content exclusions, and policy-change audit events as governed review metadata.

- [Tool call and MCP governance](../retrieval-and-tools/tool-call-and-mcp-governance.md) now requires runtime MCP allowlist enforcement and log-or-block evidence, while [progressive MCP tool discovery](../retrieval-and-tools/progressive-mcp-tool-discovery.md) treats registry recency as discovery rather than trust.

- [Agent governance infrastructure](../governance-and-risk/agent-governance-infrastructure.md) now joins AI-review policy changes, MCP runtime enforcement, system-of-record review gates, data-residency constraints, and model-provider routing into one governance record.

- [Agent environment readiness](../application-patterns/agent-environment-readiness.md) now treats sandbox lifecycle, artifacts, MCP connections, tracing, recovery, and observability as explicit execution-substrate readiness inputs.

- [User-visible progress and runtime telemetry](../application-patterns/user-visible-progress-and-runtime-telemetry.md) now tracks selected workflow mode, read-only critic roles, critic model boundaries, and long-task progress for multi-model coding workflows.

- [Instruction hierarchy and artifact boundaries](../prompt-and-instructions/instruction-hierarchy-and-artifact-boundaries.md) and [rules and knowledge layers](../context-architecture/rules-and-knowledge-layers.md) now require instruction-stack diagnostics when repository rules, custom instructions, skills, MCP metadata, and task evidence are compiled together.

- [Verification tax and acceptance gates](../verification-and-evals/verification-tax-and-acceptance-gates.md) now treats done messages as claims until session history, current files, fresh final-code checks, and tamper-resistant evidence support acceptance.

- [Research-plan-implement-review lifecycle](../agent-workflows/research-plan-implement-review-lifecycle.md) and [terminal agent workflows](../agent-workflows/terminal-agent-workflows.md) now preserve read-only research, planning artifacts, shell approvals, sandbox posture, lifecycle hooks, and final verification as handoff evidence.
