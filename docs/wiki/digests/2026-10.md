# October 2026 Development Digest

## Current Understanding

### 2026-10-27

- [Workload-owned agent identities](../governance-and-risk/agent-identity-and-delegated-authority.md) require short-lived, least-privilege credentials, owner-controlled budgets and revocation, and runtime audit evidence instead of a developer's durable session.
- [Policy-defined permission assistance](../adoption-and-operating-model/human-agent-approval-boundaries.md) keeps command, path, URL, and session-default controls explicit, with manual approval for prohibited, ambiguous, or unavailable defaults.
- [Pre-action budget and resume fences](../application-patterns/agent-session-recovery.md) require a read-only recheck and permit-or-deny evidence before a paused session performs another side effect.
- [Git-governed agent configuration](../governance-and-risk/agent-governance-infrastructure.md) separates reviewed definitions from runtime enforcement and links each run to its approved configuration.
- [Untrusted instruction provenance](../governance-and-risk/prompt-injection-and-untrusted-content.md) requires reviewing downloaded or copied guidance before it can request installation or configuration changes.
