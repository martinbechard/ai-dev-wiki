# Agent Workflows

## Current Understanding

Agent workflows cover the controlled loops that turn AI assistance into repository changes or analysis. The core loop is orient, inspect, plan, patch, verify, and carry evidence into the next step.

This topic owns work planning, visible progress, subagents, handoffs, state-change loops, tool-use sequencing, and workflow selection. It links upstream for named coding agents or frameworks and keeps the local pages focused on how to run the work.
