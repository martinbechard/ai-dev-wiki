# Retrieval And Tools

## Current Understanding

Retrieval and tools covers how agents obtain facts and perform governed actions. The local scope includes code retrieval, source selection, RAG for repositories, chunking, reranking, dynamic context requests, tool-call loops, and MCP as a practice boundary.

This topic does not catalog MCP servers or tool products. It records how retrieval and tool access are used in AI-assisted development workflows, with upstream links for entity background.
